# DocumentDrivenDX plugins

The Claude plugin marketplace for [DocumentDrivenDX](https://github.com/DocumentDrivenDX).

In Claude Code:

```
/plugin marketplace add DocumentDrivenDX/plugins
/plugin install stemma@documentdrivendx
```

| Plugin | What it does | Source |
|---|---|---|
| `stemma` | Research and write books with citations checked against your own stored copies | [DocumentDrivenDX/stemma](https://github.com/DocumentDrivenDX/stemma) |

Directories under `plugins/` are built from each plugin's source repository. Change
a plugin there, not here. Each plugin carries its own license.
